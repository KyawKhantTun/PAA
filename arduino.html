How to Learn

Code with mBlock or C++

Learning Arduino has never been easier. Start with mBlock's visual drag-and-drop blocks if you're a beginner, then graduate to writing real C++ code in the Arduino IDE.

Both tools let you control the same hardware — choose the path that fits your level and start making things blink, move, and react. 🚀
