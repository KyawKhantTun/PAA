Introduction

What is Arduino C++?

Arduino uses a simplified version of C/C++. You write code in the Arduino IDE, compile it, and upload it to the board. The code then runs directly on the microcontroller — controlling LEDs, motors, sensors, and anything you connect.

1
Download Arduino IDE from arduino.cc
Free for Windows, Mac and Linux. The official editor with built-in compiler and uploader.
2
Connect Arduino via USB
Use a USB-A to USB-B cable. Windows auto-installs drivers; Mac/Linux usually plug-and-play.
3
Select Board & Port
Tools → Board → Arduino Uno. Then Tools → Port → COM3 (Windows) or /dev/cu.usbmodem (Mac).
4
Write, Verify, Upload
Write code → click ✓ Verify to check for errors → click → Upload to flash your Arduino.
Your First Program — Hello Arduino
void setup() {
  // Runs ONCE when Arduino starts
  Serial.begin(9600);
  Serial.println("Hello, Arduino!");
}

void loop() {
  // Runs FOREVER after setup()
  Serial.println("This repeats forever!");
  delay(1000); // Wait 1 second
}
💡
Two functions, always: setup() runs once, loop() runs forever. Every Arduino program has exactly these two — nothing else is required to start.
Chapter 2

Program Structure

Every Arduino C++ program follows the same basic structure. Understanding this skeleton is the most important thing you will learn.

Basic Structure
void setup() {
  // Runs ONCE at startup
  // Initialise pins, Serial, etc.
}

void loop() {
  // Runs REPEATEDLY forever
  // Main program logic goes here
}

void myFunction() {
  // Your custom functions go here
}
Comments & Semicolons
// Single line comment

/* Multi-line
   comment here */

// Every statement MUST end with ;
digitalWrite(13, HIGH);  // correct ✓
digitalWrite(13, HIGH)   // ERROR ✗ missing ;
📌
setup() — Runs Once
Think of setup() as your preparation step. Set pin modes here, start Serial communication, initialise sensors. It runs exactly once when power is applied or the reset button is pressed.
🔁
loop() — Runs Forever
After setup() completes, loop() starts and runs continuously until power is removed. This is where your main logic lives — reading sensors, controlling outputs, checking conditions.
{ }
Curly Braces & Semicolons
Curly braces group code into blocks. Every statement inside a function MUST end with a semicolon. Missing one is the most common beginner error — the compiler tells you exactly which line.

int globalVar = 100; // everywhere

void setup() {
  int localVar = 50; // only here
}

void loop() {
  Serial.println(globalVar); // ✓ Works

}
💡
Global vs Local: Variables needed in multiple functions go at the top (global). Variables only needed in one function go inside it (local).

Chapter 5

Control Statements (If / Else)

Control statements let your program make decisions — run different code depending on sensor readings, button presses, or any condition.

If / Else If / Else
// Simple if
int temperature = 25;
if (temperature > 20) {
  Serial.println("It's warm!");
}

// If-else
int lightLevel = 30;
if (lightLevel > 100) {
  digitalWrite(13, HIGH);
} else {
  digitalWrite(13, LOW);
}

// Ladder — check multiple conditions
int score = 85;
if (score >= 90) {
  Serial.println("A - Excellent!");
} else if (score >= 80) {
  Serial.println("B - Good!");
} else {
  Serial.println("F - Fail");
}
Switch Statement
// Cleaner for multiple values
int buttonPressed = 2;
switch (buttonPressed) {
  case 1:
    Serial.println("Button 1");
    break; // prevents fall-through
  case 2:
    Serial.println("Button 2");
    break;
  default:
    Serial.println("Unknown");
}
⚠️
Always add break! Without break, execution "falls through" to the next case — a very common bug. The default case runs if no case matches.
Chapter 6

Loops

Loops repeat a block of code. They save you from copy-pasting the same instruction many times.

For Loop — specific count
// Blink LED 5 times
for (int blink = 0; blink < 5; blink++) {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}

// Fade LED up (PWM)
for (int b = 0; b <= 255; b++) {
  analogWrite(9, b);
  delay(8);
}
While & Do-While
// While — check BEFORE running
int count = 0;
while (count < 5) {
  Serial.println(count);
  count++; // MUST change to exit loop!
}

// Break & Continue
for (int i = 0; i < 10; i++) {
  if (i == 5) break;    // exit
  if (i == 3) continue; // skip
  Serial.println(i);
}
Chapter 7

Functions — Reusable Code

Functions let you wrap a block of code with a name and call it whenever you need it. They make programs shorter, cleaner, and easier to debug.

Defining & Calling Functions
// No return value (void)
void blinkLED() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}

// With parameters
void blinkTimes(int pin, int times) {
  for (int i = 0; i < times; i++) {
    digitalWrite(pin, HIGH); delay(200);
    digitalWrite(pin, LOW);  delay(200);
  }
}

// Returns a value
int add(int a, int b) {
  return a + b;
}

void loop() {
  blinkLED();          // call it
  blinkTimes(13, 3);  // 3 blinks
  int sum = add(5, 3); // sum = 8
}
📦
Why Use Functions?
Instead of writing the same 5 lines 10 times, write one function and call it 10 times. If you find a bug, fix it in one place. Functions make code modular, readable, and testable.
Arrays — Lists of Values
// Declare an array
int pins[] = {2, 3, 4, 5, 6};

// Access by index (starts at 0)
Serial.println(pins[0]); // 2

// Loop through all pins
for (int i = 0; i < 5; i++) {
  pinMode(pins[i], OUTPUT);
}
Chapter 10 & 11

Digital & Analog I/O

These four functions are the most important in all of Arduino. They are how your code talks to the physical world.

Digital I/O — On / Off
// Set up a pin first
pinMode(13, OUTPUT); // LED pin
pinMode(2,  INPUT_PULLUP); // Button

// digitalWrite — turn HIGH (on) or LOW (off)
digitalWrite(13, HIGH); // LED ON
digitalWrite(13, LOW);  // LED OFF

// digitalRead — check HIGH or LOW
int buttonState = digitalRead(2);
if (buttonState == LOW) {
  Serial.println("Button pressed!");
}
Analog I/O — Variable Values
// analogRead — returns 0 to 1023
int light = analogRead(A0);
if (light > 500) Serial.println("Bright");

// analogWrite — PWM, 0 to 255
// Only on pins: 3, 5, 6, 9, 10, 11
analogWrite(9, 128);  // 50% brightness
analogWrite(9, 255);  // Full brightness

// map() converts between ranges
int val = analogRead(A0);      // 0-1023
int pwm = map(val,0,1023,0,255); // 0-255
analogWrite(9, pwm);
Chapter 12

Time Functions — delay & millis

Timing is essential in hardware projects. delay() is simple but blocks everything. millis() is non-blocking — the professional way to time events.

delay() — Simple but Blocking
void loop() {
  digitalWrite(13, HIGH);
  delay(500);  // Wait 0.5 seconds
  digitalWrite(13, LOW);
  delay(500);
  // During delay, nothing else runs!
}
millis() — Non-Blocking Timing
unsigned long lastBlink = 0;

void loop() {
  if (millis() - lastBlink >= 500) {
    digitalWrite(13, !digitalRead(13));
    lastBlink = millis();
  }
  // Other code runs here FREELY
}
⚡
Use millis() for real projects. delay() freezes your whole program — buttons won't respond, sensors won't read. millis() lets you time events while other code keeps running smoothly.
Chapter 13

Serial Communication

Serial lets Arduino send messages to your computer through USB. It's your most powerful debugging tool — see exactly what values your sensors are reading in real time.

Serial Monitor — Send & Receive
void setup() {
  Serial.begin(9600); // Start at 9600 baud
}

void loop() {
  Serial.print("Value: ");
  Serial.println(42);

  int sensor = analogRead(A0);
  Serial.print("Sensor: ");
  Serial.println(sensor);

  // Read typed input from monitor
  if (Serial.available()) {
    char c = Serial.read();
    if (c == '1') digitalWrite(13, HIGH);
    if (c == '0') digitalWrite(13, LOW);
  }
  delay(1000);
}
FunctionWhat it does
Serial.begin(9600)Start serial at 9600 baud speed
Serial.print(val)Send text/number (no newline)
Serial.println(val)Send text/number (with newline)
Serial.read()Read one character from input
Serial.available()Check if data is waiting to be read
Serial.write(byte)Send a raw byte value
🔍
Open Serial Monitor: Tools → Serial Monitor (Ctrl+Shift+M). Make sure the baud rate matches your Serial.begin() value — 9600 is standard.
Chapter 14

Libraries — Pre-Written Code

Libraries are packages of functions someone else wrote. Instead of programming a sensor from scratch, you include one line and get 20 useful functions instantly.

Using a Library
// 1. Include at the top of your sketch
#include <Servo.h>

// 2. Create an object
Servo myServo;

void setup() {
  myServo.attach(9); // pin 9
}

void loop() {
  myServo.write(0);   delay(1000);
  myServo.write(90);  delay(1000);
  myServo.write(180); delay(1000);
}
①
Open Library Manager
Sketch → Include Library → Manage Libraries (or Ctrl+Shift+I)
②
Search & Install
Type the library name (e.g. "DHT sensor library"), click Install. Downloads and adds to IDE automatically.
③
Include & Use
Add #include <LibraryName.h> at the top. Now all the library's functions are available.
LibraryWhat it controls
Servo.hServo motor position
DHT.hTemperature & humidity sensors
LiquidCrystal.hLCD displays
Wire.hI2C sensors & modules
SPI.hSPI communication protocol
Chapter 15

Debugging Tips

Bugs happen to every programmer. Here's how to find and fix them quickly.

❌
Syntax Error
Missing semicolon, bracket, or typo. Code won't compile. The error message shows the line number — go there and look for what's missing.
🔢
Variable Not Declared
Used a variable without declaring its type first. Add the type (int, float, bool…) before the first use. Check spelling — C++ is case-sensitive.
🤔
Logic Error
Code compiles and uploads but does the wrong thing. Use Serial.println() to print variable values and trace where things go wrong.
Debugging with Serial.println()
void loop() {
  Serial.println("--- Loop start ---");

  int value = analogRead(A0);
  Serial.print("Sensor: "); Serial.println(value);

  if (value > 500) {
    Serial.println("Triggered!");
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
  delay(500); // Slow down to read output
}
