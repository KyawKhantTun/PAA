Introduction

What is mBlock?

mBlock is a Scratch-based visual programming environment made for Arduino. Instead of typing code, you drag and snap colourful blocks together. It compiles to real Arduino code behind the scenes — everything you build actually runs on the board.

🧩
Visual Blocks

Every action — reading a sensor, blinking an LED, playing a sound — is a coloured block. Snap them together like puzzle pieces to build programs intuitively.

⚡
Real Arduino Code

mBlock compiles your blocks into real C++ that uploads to the Arduino Uno. You can even switch to code view to see the generated program — a great bridge to C++.

🚀
Start in Minutes

No installation needed if you use the web version. Connect your Arduino, select the board, and start uploading programs within 5 minutes of opening the browser.

Getting Started

How to Get Started

From zero to blinking LED in under 10 minutes. Follow these steps to set up mBlock and run your first program.

1
Open mBlock in your browser
Go to mblock.makeblock.com. No account needed. Click "Create" to start a new project.
2
Select Arduino as the device
Click "+" in the Devices panel on the left. Choose "Arduino Uno" and confirm. The block palette updates to show Arduino blocks.
3
Connect your Arduino
Plug in via USB, click "Connect" and select the COM port. Install the mLink helper app if prompted — it bridges browser and board.
4
Drag blocks and upload
Drag "set digital pin 13 output HIGH" and "wait 1 seconds" into a loop. Click "Upload" and watch the built-in LED blink!

Core Blocks

Essential mBlock Blocks

These are the most important blocks you'll use in almost every Arduino mBlock project. Learn what each one does.

set digital pin [13] output [HIGH]
Set Digital Pin
Turn a digital output pin ON (HIGH = 5V) or OFF (LOW = 0V). Used to control LEDs, buzzers, relays.
wait [1] seconds
Wait / Delay
Pause the program for a set time. Essential for blinking LEDs, timing sequences, and debounce.
read digital pin [2]
Read Digital Pin
Returns HIGH or LOW. Use to check if a button is pressed, or if a sensor threshold is triggered.
read analog pin [A0]
Read Analog Pin
Returns 0–1023. Use with potentiometers, LDRs, and other analog sensors to get variable readings.
set pwm pin [9] to [128]
Set PWM Pin
Outputs a PWM signal (0–255) on a PWM-capable pin. Use to dim LEDs or control servo/motor speed.
forever
Forever Loop
Runs all blocks inside it continuously — equivalent to the loop() function in C++. Most programs use this.
if <condition> then
If / Else
Conditional logic. Run blocks only when a condition is true — e.g., "if button pressed, then turn LED on."
set servo pin [9] to [90]°
Set Servo Angle
Moves a servo motor to the specified angle (0–180°). No library setup needed — mBlock handles it.
mBlock vs C++

Which Should You Use?

Both mBlock and C++ control the same Arduino hardware. The difference is how you express the logic. Here's how they compare.

FeaturemBlockArduino C++
Learning curveVery easyModerate
Typing requiredNoneYes
Full control over hardwareMost featuresComplete
External librariesLimited selectionAll libraries
Code readabilityVery visualText-based
Best forLearning fundamentalsReal projects
💡

Our recommendation: Start with mBlock to understand the concepts — loops, conditions, pins, sensors. Once you're comfortable, move to C++ for full control. The ideas transfer directly; only the syntax changes.
