💡 Light It Up
No Code Needed LED · Resistor · Breadboard 5 Sub-Projects ⏱ 45–60 min
Difficulty
▾
Introduction

In this project we build a series of light circuits — no coding yet. You'll learn how circuits work, what components are, and how to wire an LED on a breadboard. By the end you'll have built 5 different circuits using LEDs, resistors, switches, a potentiometer, and an RGB LED.

🧰
What You Need
Arduino Uno, breadboard, LEDs (multiple colours), 220Ω–330Ω resistors, push buttons, potentiometer, RGB LED, jumper wires.
⚡
What You'll Learn
How circuits work, power rails, LED polarity, resistors, series vs parallel wiring, switches, potentiometers, RGB mixing.
🌍
Real World Use
Power indicator lights, traffic signals, dimmer switches, RGB mood lighting, status LEDs in every electronic device.
  • A circuit needs: a power source, wires, components, and must form a complete loop.
  • The red rail on the breadboard carries 5V power; the blue rail is ground (GND).
  • LEDs only work in one direction (polarity) — longer leg is positive (anode).
  • Always use a 220Ω–330Ω resistor in series with an LED to protect it.
  • Switches break the circuit by default (OFF) and complete it when pressed (ON).
  • A potentiometer is a variable resistor — twisting it changes resistance and LED brightness.
  • An RGB LED has 4 pins: one ground (longest), and one for each colour (R, G, B).

Project 02: Light Coding — write your first Arduino code and make LEDs blink with programming

Difficulty
▾
Introduction

Now we add code to our circuits! Using mBlock, we control LEDs with digital pin outputs — turning them on, off, blinking, sequencing, and even sending SOS in morse code. This is where software meets hardware for the first time.

🧰
What You Need
Arduino Uno, breadboard, 3 LEDs (red, yellow, green), 220Ω resistors, USB cable, mBlock installed.
⚡
What You'll Learn
digitalWrite HIGH/LOW, forever loops, wait blocks, controlling multiple pins, traffic light sequence, morse code SOS.
🌍
Real World Use
Traffic lights, notification LEDs, emergency signals, animated signage, status indicators on electronics.
  • Connect pin 13 to the breadboard red rail — when code turns pin 13 HIGH, the rail gets 5V.
  • Use "set digital pin 13 output as HIGH/LOW" blocks to control the LED.
  • A "forever" loop makes code repeat — just like Arduino's loop() function.
  • Connect 3 LEDs to pins 13, 12, 11 to control them independently.
  • Traffic lights: Green 5s → Yellow 1s → Red 5s, repeating in a loop.
  • SOS morse code: 3 short blinks (dots) + 3 long blinks (dashes) + 3 short blinks.
  • Use "repeat 3" blocks to avoid duplicating code for the SOS pattern.

Project 03: Switch It Up — add input switches and make the Arduino respond to button presses
Start Project 03 →
Basic · Project 03
🔘 Switch It Up
mBlockPush Button · digitalRead · Input5 Sub-Projects⏱ 60–90 min
Difficulty
▾
Introduction

Switches are input devices — they let the user talk back to the Arduino. In this project you'll build circuits with one and two switches (series and parallel), then code software switches and physical input switches that Arduino can detect and respond to.

🧰
What You Need
Arduino Uno, breadboard, push button switches (2–3), LEDs, 220Ω resistors, 10kΩ resistor (pull-down), jumper wires, mBlock.
⚡
What You'll Learn
How switches work, series vs parallel switch wiring, software toggle switches, pull-down resistors, digitalRead(), conditional code.
🌍
Real World Use
Doorbells, keyboard keys, game controllers, security alarm triggers, elevator buttons, vending machines.
  • Switches are placed over the ravine (gap) of the breadboard — it can only go on correctly one way.
  • Series switches: both must be pressed for the circuit to complete (AND logic).
  • Parallel switches: either one being pressed completes the circuit (OR logic).
  • A software switch uses keyboard input in mBlock to trigger the Arduino — no physical button needed.
  • A toggle switch changes state each time you press — if ON, press turns it OFF, and vice versa.
  • A pull-down resistor (10kΩ to GND) keeps pin 2 at a stable LOW (0) when the button is not pressed.
  • When the button is pressed, 5V travels through the switch to pin 2, making it HIGH (1).

Project 04: Electric Piano — play musical notes with fruit or buttons using analog input
Start Project 04 →
Basic · Project 04
🎹 Electric Piano
mBlock2 VersionsAnalog Input · Sound · Buttons⏱ 90–120 min
Difficulty
▾
Introduction

Build a working electric piano! This project has two versions: Version A uses fruit or Play-Doh as touch-sensitive keys (capacitive touch via analog pins), and Version B uses physical push buttons as piano keys. Both play musical notes through mBlock.

🍌
What You Need (A)
Arduino Uno, 6× resistors (1MΩ–10MΩ), conductive material (bananas, grapes, or Play-Doh) × 6, mBlock with Sound Extension.
🎹
What You Need (B)
Arduino Uno, 8× push buttons, 8× 1kΩ resistors, buzzer (for upload mode), jumper wires, mBlock.
🌍
Real World Use
Musical instruments, touch-sensitive interfaces, interactive art installations, accessibility devices, STEM education.
  • Version A: High-resistance pull-up resistors (1MΩ+) connect 5V to analog pins A0–A5. Values stay HIGH (1000+) when floating.
  • Touch the conductive key while holding the ground wire — your body conducts electricity, pulling the value LOW.
  • Code checks: if analog value < 700, play a note via broadcast.
  • Version B: 8 push buttons wired to digital pins 6–13 with pull-down resistors.
  • Each button plays a different musical note: Do (C4), Re (D4), Mi (E4), Fa (F4), So (G4), La (A4), Ti (B4), High Do (C5).
  • In upload mode, connect a buzzer to use tone() — no computer sound needed.
Sub-Projects — Circuit & Code
Fruit / Play-Doh keys — 1MΩ+ resistors on analog pins A0–A5, ground wire held by player
🧩 mBlock

Forever loop: if analog pin A5 < Trigger (800) → broadcast "Piano A" → wait until A5 > Trigger.

💻 C++
Arduino C++ (Upload Mode)
// Fruit piano — analog touch
const int buzzer = 5;
int notes[] = {262,294,330,349,392,440};
const int threshold = 700;

void setup() {}

void loop() {
  for (int i=0;i<6;i++) {
    if (analogRead(i) < threshold) {
      tone(buzzer, notes[i], 300);
      while(analogRead(i) < threshold);
    }
  }
}
8 push buttons on pins 6–13 with 1kΩ pull-down resistors, buzzer on pin 5
🧩 mBlock
💻 C++
Arduino C++ (Upload Mode + Buzzer)
// Button piano: pins 6-13, buzzer pin 5
const int buzzer = 5;
int btns[]  = {6,7,8,9,10,11,12,13};
int notes[] = {262,294,330,349,392,440,494,523};
// Do  Re   Mi   Fa   So  La  Ti  Do(hi)

void setup() {
  for(int i=0;i<8;i++) pinMode(btns[i], INPUT);
}
void loop() {
  for(int i=0;i<8;i++) {
    if (digitalRead(btns[i]) == HIGH) {
      tone(buzzer, notes[i]);
      while(digitalRead(btns[i]) == HIGH);
      noTone(buzzer);
    }
  }
}

Project 05: Reaction Race — a 2-player game combining buttons, LEDs, and game logic
Start Project 05 →
Basic · Project 05
🏁 Reaction Race
mBlockMultiplayer GameButtons · Traffic Lights · Variables
Difficulty
▾
Introduction

Build a 2-player reaction speed game! Both players have a button. A traffic light (Red → Yellow → Green) counts down on real LEDs. The first player to press their button after the green light scores a point. First to 5 wins. You'll combine everything you've learned — circuits, inputs, outputs, and game logic.

🧰
What You Need
Arduino Uno, breadboard, 2× push buttons, 3× LEDs (Red, Yellow, Green), 2× 10kΩ resistors, 3× 220Ω resistors, jumper wires, mBlock.
⚡
What You'll Learn
Combining inputs & outputs in one project, game logic with variables, player scores, anti-cheat detection, sprites and game design.
🌍
Real World Use
Arcade games, quiz buzzers, drag racing start lights, reaction time training devices, game show buzzers.
  • Buttons connect to pins 2 and 3 via pull-down resistors — LOW by default, HIGH when pressed.
  • Traffic LEDs: Red=pin 13, Yellow=pin 12, Green=pin 11 — same wiring as Project 2.
  • Game logic: spacebar starts the game → Red 1s → Yellow 1s → Green → detect who presses first.
  • Use mBlock sprites for each player (Panda, Bee) with score variables displayed on screen.
  • Anti-cheat: if button is already held when Green lights up, it doesn't count — must release and re-press.
  • Challenge: detect a tie (both buttons within same loop cycle) and display "TIE!" message.
Sub-Projects — Circuit & Code
2 input buttons (pins 2 & 3) with 10kΩ pull-down resistors

Wire Player 1's button to pin 2 and Player 2's button to pin 3. Each needs a 10kΩ pull-down resistor to GND so pins read stable LOW when the button is not pressed.

Traffic light LEDs — Red=pin 13, Yellow=pin 12, Green=pin 11 (same as Project 2)

Wire Red LED to pin 11, Yellow to pin 12, Green to pin 13 — each with a 220Ω resistor. This is the same traffic light circuit from Project 2.

Full game circuit — both buttons + traffic light LEDs combined
🧩 mBlock

Game flow: Space pressed → Red LED (1s) → Yellow (1s) → Green → forever loop checking pins 2 & 3 → winner gets +1 score → repeat.

💻 C++
Arduino C++
int p1=2, p2=3;     // button pins
int r=11, y=12, g=13; // LED pins
int score1=0, score2=0;

void setup() {
  pinMode(p1,INPUT); pinMode(p2,INPUT);
  pinMode(r,OUTPUT); pinMode(y,OUTPUT);
  pinMode(g,OUTPUT);
  Serial.begin(9600);
}
void runRace() {
  digitalWrite(r,HIGH); delay(1000);
  digitalWrite(r,LOW);
  digitalWrite(y,HIGH); delay(1000);
  digitalWrite(y,LOW);
  digitalWrite(g,HIGH);
  while(true) {
    if(digitalRead(p1)==HIGH) { score1++; break; }
    if(digitalRead(p2)==HIGH) { score2++; break; }
  }
  digitalWrite(g,LOW);
  Serial.print("P1:"); Serial.print(score1);
  Serial.print(" P2:"); Serial.println(score2);
}
void loop() {
  delay(3000);
  runRace();
}
