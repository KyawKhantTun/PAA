Introduction

In this project we build a series of light circuits — no coding yet. You'll learn how circuits work, what components are, and how to wire an LED on a breadboard. By the end you'll have built 5 different circuits using LEDs, resistors, switches, a potentiometer, and an RGB LED.

🧰
What You Need
Arduino Uno, breadboard, LEDs (multiple colours), 220Ω–330Ω resistors, push buttons, potentiometer, RGB LED, jumper wires.
⚡
What You'll Learn
How circuits work, power rails, LED polarity, resistors, series vs parallel wiring, switches, potentiometers, RGB mixing.
🌍
Real World Use
Power indicator lights, traffic signals, dimmer switches, RGB mood lighting, status LEDs in every electronic device.
  • A circuit needs: a power source, wires, components, and must form a complete loop.
  • The red rail on the breadboard carries 5V power; the blue rail is ground (GND).
  • LEDs only work in one direction (polarity) — longer leg is positive (anode).
  • Always use a 220Ω–330Ω resistor in series with an LED to protect it.
  • Switches break the circuit by default (OFF) and complete it when pressed (ON).
  • A potentiometer is a variable resistor — twisting it changes resistance and LED brightness.
  • An RGB LED has 4 pins: one ground (longest), and one for each colour (R, G, B).

Introduction

Now we add code to our circuits! Using mBlock, we control LEDs with digital pin outputs — turning them on, off, blinking, sequencing, and even sending SOS in morse code. This is where software meets hardware for the first time.

🧰
What You Need
Arduino Uno, breadboard, 3 LEDs (red, yellow, green), 220Ω resistors, USB cable, mBlock installed.
⚡
What You'll Learn
digitalWrite HIGH/LOW, forever loops, wait blocks, controlling multiple pins, traffic light sequence, morse code SOS.
🌍
Real World Use
Traffic lights, notification LEDs, emergency signals, animated signage, status indicators on electronics.
  • Connect pin 13 to the breadboard red rail — when code turns pin 13 HIGH, the rail gets 5V.
  • Use "set digital pin 13 output as HIGH/LOW" blocks to control the LED.
  • A "forever" loop makes code repeat — just like Arduino's loop() function.
  • Connect 3 LEDs to pins 13, 12, 11 to control them independently.
  • Traffic lights: Green 5s → Yellow 1s → Red 5s, repeating in a loop.
  • SOS morse code: 3 short blinks (dots) + 3 long blinks (dashes) + 3 short blinks.
  • Use "repeat 3" blocks to avoid duplicating code for the SOS pattern.

Project 03: Switch It Up — add input switches and make the Arduino respond to button presses

Basic · Project 03
🔘 Switch It Up
mBlockPush Button · digitalRead · Input5 Sub-Projects⏱ 60–90 min
Difficulty
▾
Introduction

Switches are input devices — they let the user talk back to the Arduino. In this project you'll build circuits with one and two switches (series and parallel), then code software switches and physical input switches that Arduino can detect and respond to.

🧰
What You Need
Arduino Uno, breadboard, push button switches (2–3), LEDs, 220Ω resistors, 10kΩ resistor (pull-down), jumper wires, mBlock.
⚡
What You'll Learn
How switches work, series vs parallel switch wiring, software toggle switches, pull-down resistors, digitalRead(), conditional code.
🌍
Real World Use
Doorbells, keyboard keys, game controllers, security alarm triggers, elevator buttons, vending machines.
  • Switches are placed over the ravine (gap) of the breadboard — it can only go on correctly one way.
  • Series switches: both must be pressed for the circuit to complete (AND logic).
  • Parallel switches: either one being pressed completes the circuit (OR logic).
  • A software switch uses keyboard input in mBlock to trigger the Arduino — no physical button needed.
  • A toggle switch changes state each time you press — if ON, press turns it OFF, and vice versa.
  • A pull-down resistor (10kΩ to GND) keeps pin 2 at a stable LOW (0) when the button is not pressed.
  • When the button is pressed, 5V travels through the switch to pin 2, making it HIGH (1).

Project 04: Electric Piano — play musical notes with fruit or buttons using analog input

Basic · Project 04
🎹 Electric Piano
mBlock2 VersionsAnalog Input · Sound · Buttons⏱ 90–120 min
Difficulty
▾
Introduction

Build a working electric piano! This project has two versions: Version A uses fruit or Play-Doh as touch-sensitive keys (capacitive touch via analog pins), and Version B uses physical push buttons as piano keys. Both play musical notes through mBlock.

🍌
What You Need (A)
Arduino Uno, 6× resistors (1MΩ–10MΩ), conductive material (bananas, grapes, or Play-Doh) × 6, mBlock with Sound Extension.
🎹
What You Need (B)
Arduino Uno, 8× push buttons, 8× 1kΩ resistors, buzzer (for upload mode), jumper wires, mBlock.
🌍
Real World Use
Musical instruments, touch-sensitive interfaces, interactive art installations, accessibility devices, STEM education.
  • Version A: High-resistance pull-up resistors (1MΩ+) connect 5V to analog pins A0–A5. Values stay HIGH (1000+) when floating.
  • Touch the conductive key while holding the ground wire — your body conducts electricity, pulling the value LOW.
  • Code checks: if analog value < 700, play a note via broadcast.
  • Version B: 8 push buttons wired to digital pins 6–13 with pull-down resistors.
  • Each button plays a different musical note: Do (C4), Re (D4), Mi (E4), Fa (F4), So (G4), La (A4), Ti (B4), High Do (C5).
  • In upload mode, connect a buzzer to use tone() — no computer sound needed.
Sub-Projects — Circuit & Code
Fruit / Play-Doh keys — 1MΩ+ resistors on analog pins A0–A5, ground wire held by player
🧩 mBlock

// Fruit piano — analog touch
const int buzzer = 5;
int notes[] = {262,294,330,349,392,440};
const int threshold = 700;

void setup() {}

void loop() {
  for (int i=0;i<6;i++) {
    if (analogRead(i) < threshold) {
      tone(buzzer, notes[i], 300);
      while(analogRead(i) < threshold);
    }
  }
}

Introduction

Build a 2-player reaction speed game! Both players have a button. A traffic light (Red → Yellow → Green) counts down on real LEDs. The first player to press their button after the green light scores a point. First to 5 wins.

🧰
What You Need

⚡

🌍
Real World Use
Arcade games, quiz buzzers, drag racing start lights, reaction time training devices, game show buzzers.

  • Traffic LEDs: Red=pin 13, Yellow=pin 12, Green=pin 11 — same wiring as Project 2.
  • Game logic: spacebar starts the game → Red 1s → Yellow 1s → Green → detect who presses first.
  • Anti-cheat: if button is already held when Green lights up, it doesn't count.

  digitalWrite(g,LOW);

  Serial.print(" P2:");Serial.println(score2);
}

  delay(3000); runRace();
}

Intermediate · Project 06
🌻 Setting It Up
mBlockPhotoresistor · Servo Motor2 Sub-Projects⏱ 60–90 min
Difficulty
▾
Introduction

In this project we use a photoresistor (light sensor) to control a servo motor. As the light changes, the servo rotates — just like a sunflower tracking the sun! You'll learn how analog sensors feed real-world data into code, and how servo motors respond with precise motion.

🧰
What You Need
Arduino Uno, photoresistor (LDR), servo motor (SG90), 10kΩ or 220Ω resistor, jumper wires, mBlock.
⚡
What You'll Learn
Analog sensor reading with analogRead(), servo control with the Servo library, mapping values between ranges with map(), and conditional logic for direction control.
🌍
Real World Use
Solar panel trackers, automatic window blinds, motion-activated camera mounts, self-orienting antennas, light-following robots.
  • A photoresistor changes resistance depending on light — more light = lower resistance = higher analog reading.
  • The SG90 servo rotates from 0° to 180°. Connect its orange signal wire to a PWM pin (e.g. pin 9).
  • Use map(value, 0, 1023, 0, 180) to translate the sensor reading into a servo angle.
  • The Full project uses two photoresistors so the servo tracks which side has more light.
Sub-Projects — Circuit & Code
Photoresistor on A0 with 10kΩ pull-down resistor; SG90 signal wire to Pin 9
🧠
Algorithm — Basic LDR Servo
Understand the logic before writing code
  1. 1
    Read the analog value from the photoresistor on A0 — this gives a number from 0 to 1023.
  2. 2
    Map that value to a servo angle: map(lightValue, 0, 1023, 0, 180) converts 0→0° and 1023→180°.
  3. 3
    Write the mapped angle to the servo using servo.write(angle).
  4. 4
    Add a small delay so the servo has time to physically move before the next reading.
  5. 5
    Loop forever — the servo will continuously track any light changes.
🧩 mBlock
💻 C++
Arduino C++
#include <Servo.h>

Servo myServo;
const int ldrPin = A0;
const int servoPin = 9;

void setup() {
  myServo.attach(servoPin);
  Serial.begin(9600);
}

void loop() {
  int lightVal = analogRead(ldrPin);
  int angle = map(lightVal,0,1023,0,180);
  myServo.write(angle);
  Serial.print("Light: "); Serial.print(lightVal);
  Serial.print("  Angle: "); Serial.println(angle);
  delay(100);
}
Two LDRs on A0 (left) and A1 (right); servo signal on Pin 9.
🧠
Algorithm — Dual LDR Sunflower
Two sensors compete — the brighter side wins
  1. 1
    Read LDR left (A0) and LDR right (A1) simultaneously.
  2. 2
    IF left < right (left side is brighter) → rotate servo toward 0° (left).
  3. 3
    ELSE IF right < left (right side is brighter) → rotate servo toward 180° (right).
  4. 4
    ELSE both are equal → hold current position.
  5. 5
    Move the servo one degree at a time with a small delay for realistic motion.
🧩 mBlock
💻 C++
Arduino C++
#include <Servo.h>

Servo myServo;
int currentAngle = 90;

void setup() {
  myServo.attach(9);
  myServo.write(currentAngle);
}

void slowMove(int target) {
  while(currentAngle != target) {
    currentAngle += (target > currentAngle) ? 1 : -1;
    myServo.write(currentAngle);
    delay(15);
  }
}

void loop() {
  int L = analogRead(A0);
  int R = analogRead(A1);
  int diff = L - R;
  if(diff < -50)      slowMove(0);
  else if(diff > 50) slowMove(180);
  delay(50);
}

Project 07: Intruder! Intruder! — build a proximity alarm with an ultrasonic sensor and buzzer

Intermediate · Project 07
🚨 Intruder! Intruder!
Upload ModeUltrasonic · BuzzerSecurity Alarm⏱ 45–75 min
Difficulty
▾
Introduction

Build a cookie-jar security alarm! An ultrasonic sensor constantly measures the distance in front of it. If anything gets closer than your threshold (e.g. 30 cm), a piezo buzzer sounds the alarm.

🧰
What You Need
Arduino Uno, HC-SR04 ultrasonic sensor, piezo buzzer, breadboard, jumper wires. Upload mode required.
⚡
What You'll Learn
How ultrasonic distance sensing works (ping → echo → time → distance), pulseIn(), tone() and noTone(), threshold-based triggering.
🌍
Real World Use
Parking sensors, motion-triggered security systems, automatic door openers, robotic obstacle detection.
  • Distance formula: distance = duration / 58.0 (duration in microseconds → centimetres).
  • Wiring: TRIG → Pin 9, ECHO → Pin 10, Buzzer + → Pin 8, Buzzer – → GND.
  • Always trigger with a 10 µs pulse, then wait for the echo.
Circuit & Code
HC-SR04: VCC→5V, GND→GND, TRIG→Pin 9, ECHO→Pin 10.
🧩 mBlock

Forever → read ultrasonic on A0 → save to variable Distance → wait 0.2s. Optional: print Distance to serial via broadcast.

💻 C++
Arduino C++ — Distance Reading
const int trigPin = 9;
const int echoPin = 10;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  Serial.begin(9600);
}

long readDistance() {
  digitalWrite(trigPin, LOW);  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  long dur = pulseIn(echoPin, HIGH);
  return dur / 58;
}

void loop() {
  long cm = readDistance();
  Serial.print("Distance: ");
  Serial.print(cm);
  Serial.println(" cm");
  delay(200);
}
Piezo buzzer: positive leg → Pin 8, negative leg → GND.
🧩 mBlock

When clicked → forever → set digital pin 8 output HIGH → wait 0.5s → set digital pin 8 output LOW → wait 0.5s.

🧠
Algorithm — Proximity Alarm
Think through the logic before coding
  1. 1
    Fire a 10 µs pulse on TRIG to send an ultrasonic ping.
  2. 2
    Use pulseIn(ECHO, HIGH) to measure how long the echo takes to return.
  3. 3
    Convert to centimetres: distance = duration / 58.
  4. 4
    IF distance < threshold (e.g. 30 cm) → sound the buzzer with tone(pin, frequency).
  5. 5
    ELSE → silence with noTone(pin).
  6. 6
    Repeat every 200 ms.
🧩 mBlock

Forever → read ultrasonic → save to Distance → if Distance < 30 → tone pin 8 at 2000 Hz → wait 0.1s → tone at 1000 Hz → else → noTone → wait 0.2s.

💻 C++
Arduino C++ — Full Security Alarm
const int trigPin = 9, echoPin = 10, buzzerPin = 8;
const int threshold = 30;

void setup() {
  pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT);
  pinMode(buzzerPin, OUTPUT); Serial.begin(9600);
}

long readDistance() {
  digitalWrite(trigPin, LOW);  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  return pulseIn(echoPin, HIGH) / 58;
}

void loop() {
  long dist = readDistance();
  Serial.print("Distance: "); Serial.print(dist); Serial.println(" cm");
  if (dist > 0 && dist < threshold) {
    tone(buzzerPin, 2000); delay(100);
    tone(buzzerPin, 1000); delay(100);
  } else {
    noTone(buzzerPin); delay(200);
  }
}

🚗 How it works

The ultrasonic sensor fires a ping every 200 ms. When the echo returns in under the threshold time (car detected at <20 cm), the servo rotates to 90° to raise the barrier. After 3 seconds — enough time for a model car to pass — the servo returns to 0° and the gate closes.

Algorithm — Simple Parking Gate
Detect → Open → Wait → Close → Repeat
  1. 1
    Start with gate closed: write 0° to the servo.
  2. 2
    Fire a 10 µs pulse on TRIG, read the echo duration from ECHO, convert to cm: dist = pulseIn(ECHO, HIGH) / 58.
  3. 3

  4. 4

  5. 5

  6. 6

#include <Servo.h>

Servo gateServo;
const int TRIG = 9, ECHO = 10;
const int SERVO_PIN = 5;
const int CAR_DIST = 20; // cm

long readDistance() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);

}

Arduino C++ — Full Car Parking System
#include <Servo.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// LCD: I2C address 0x27, 16 cols, 2 rows
LiquidCrystal_I2C lcd(0x27, 16, 2);
Servo gateServo;

const int TRIG=9, ECHO=10, SERVO_PIN=5;
const int GREEN_LED=7, RED_LED=6;
const int CAR_DIST=20;     // cm — trigger distance
const int TOTAL_SPACES=5;
int availableSpaces = TOTAL_SPACES;

long readDistance() {
  digitalWrite(TRIG,LOW);  delayMicroseconds(2);
  digitalWrite(TRIG,HIGH); delayMicroseconds(10);
  digitalWrite(TRIG,LOW);
  long d = pulseIn(ECHO, HIGH, 25000);
  return d ? d/58 : 999;
}

void showStatus(long dist) {
  lcd.setCursor(0,0);
  lcd.print("Dist: "); lcd.print(dist);
  lcd.print(" cm   "); // Trailing spaces clear old chars
  lcd.setCursor(0,1);
  if (availableSpaces > 0) {
    lcd.print("Spaces: "); lcd.print(availableSpaces);
    lcd.print("        ");
    digitalWrite(GREEN_LED,HIGH); digitalWrite(RED_LED,LOW);
  } else {
    lcd.print("PARKING FULL!   ");
    digitalWrite(GREEN_LED,LOW);  digitalWrite(RED_LED,HIGH);
  }
}

void carArrived() {
  lcd.clear();
  lcd.setCursor(0,0); lcd.print("  WELCOME!  :)  ");
  lcd.setCursor(0,1); lcd.print("Gate opening... ");
  gateServo.write(90);   // Open
  delay(3000);
  gateServo.write(0);    // Close
  availableSpaces--;
  lcd.clear();
  lcd.setCursor(0,0); lcd.print("Space taken!");
  lcd.setCursor(0,1); lcd.print("Left: ");
  lcd.print(availableSpaces);
  delay(2000);
}

void setup() {
  lcd.init(); lcd.backlight();
  gateServo.attach(SERVO_PIN); gateServo.write(0);
  pinMode(TRIG,OUTPUT); pinMode(ECHO,INPUT);
  pinMode(GREEN_LED,OUTPUT); pinMode(RED_LED,OUTPUT);
  Serial.begin(9600);
  // Splash screen
  lcd.setCursor(0,0); lcd.print("Car Park Ready!");
  lcd.setCursor(0,1); lcd.print("Spaces: "); lcd.print(TOTAL_SPACES);
  digitalWrite(GREEN_LED,HIGH);
  delay(2000);
  lcd.clear();
}

void loop() {
  long dist = readDistance();
  Serial.print("Dist: "); Serial.println(dist);

  if (availableSpaces == 0) {
    // Car park full — gate stays shut
    lcd.setCursor(0,0); lcd.print("PARKING FULL!   ");
    lcd.setCursor(0,1); lcd.print("No spaces left  ");
    digitalWrite(GREEN_LED,LOW); digitalWrite(RED_LED,HIGH);
    delay(500);
    return;
  }

  showStatus(dist);

  if (dist > 0 && dist < CAR_DIST) {
    carArrived();
  }
  delay(200);
}

void setup(){
  pinMode(PIN_BRAKE,OUTPUT);pinMode(PIN_LEFT,OUTPUT);

}

  if(millis()-lastBlink>=500){blinkState=!blinkState;lastBlink=millis();}
}

  updateBlink();
  digitalWrite(PIN_LEFT,blinkState);
  digitalWrite(PIN_RIGHT,blinkState);
}

  updateBlink();
  digitalWrite(PIN_LEFT,blinkState);
  digitalWrite(PIN_RIGHT,LOW);
}
void signalRight(){
  updateBlink();

  digitalWrite(PIN_LEFT,LOW);
}

  unsigned long t=millis();
  if(t%8000<2000)      digitalWrite(PIN_BRAKE,HIGH);

Algorithm — Bluetooth Remote Control
Phone sends a character → Arduino reads it → calls the right function
  1. 1
    Initialise SoftwareSerial BT(2, 4) at 9600 baud — same speed the HC-05/06 uses by default.
  2. 2
    Every loop, check BT.available() — returns true when a character has arrived from the phone.
  3. 3
    Read the character: char cmd = BT.read().
  4. 4
    Use a switch/case to match 'F', 'B', 'L', 'R', 'S', 'H' to the matching movement or light function.
  5. 5
    IF cmd is a digit '0'–'9' → map it to a speed value: carSpeed = map(cmd - '0', 0, 9, 50, 255).
  6. 6
    The movement functions use carSpeed instead of a fixed value, so the phone controls both direction and throttle.
  7. 7
    Echo the command back via USB Serial (Serial.println(cmd)) for debugging — visible in Arduino's Serial Monitor.
🧩 mBlock

Use the Bluetooth Serial extension. Forever: if Bluetooth received = "F" → call forward block. If "B" → backward. If "L" → turnLeft. If "R" → turnRight. If "S" → stopCar. Chain all cases with if/else if blocks.

💻 C++
Arduino C++ — Bluetooth Remote Control
#include <SoftwareSerial.h>

// HC-05/06: TX→Pin2 (Arduino RX), RX→Pin4 via voltage divider
SoftwareSerial BT(2, 4);

// ── L298N Motor Pins ─────────────────────────────────────
const int ENA=5,IN1=6,IN2=7;
const int ENB=3,IN3=8,IN4=9;

// ── Lights ───────────────────────────────────────────────
const int PIN_BRAKE=13,PIN_LEFT=12,PIN_RIGHT=11,PIN_REV=10;
unsigned long lastBlink=0; bool blinkState=false;

int carSpeed = 200; // Default speed (0–255)

void updateBlink(){
  if(millis()-lastBlink>=500){blinkState=!blinkState;lastBlink=millis();}
}
void allLightsOff(){
  digitalWrite(PIN_BRAKE,LOW);digitalWrite(PIN_LEFT,LOW);
  digitalWrite(PIN_RIGHT,LOW);digitalWrite(PIN_REV,LOW);
}

void forward(){
  allLightsOff();
  digitalWrite(IN1,HIGH);digitalWrite(IN2,LOW);
  digitalWrite(IN3,HIGH);digitalWrite(IN4,LOW);
  analogWrite(ENA,carSpeed);analogWrite(ENB,carSpeed);
}
void backward(){
  allLightsOff(); digitalWrite(PIN_REV,HIGH);
  digitalWrite(IN1,LOW);digitalWrite(IN2,HIGH);
  digitalWrite(IN3,LOW);digitalWrite(IN4,HIGH);
  analogWrite(ENA,carSpeed);analogWrite(ENB,carSpeed);
}
void turnLeft(){
  updateBlink(); digitalWrite(PIN_LEFT,blinkState);
  analogWrite(ENA,0);
  digitalWrite(IN3,HIGH);digitalWrite(IN4,LOW);
  analogWrite(ENB,carSpeed);
}
void turnRight(){
  updateBlink(); digitalWrite(PIN_RIGHT,blinkState);
  analogWrite(ENB,0);
  digitalWrite(IN1,HIGH);digitalWrite(IN2,LOW);
  analogWrite(ENA,carSpeed);
}
void stopCar(){
  analogWrite(ENA,0);analogWrite(ENB,0);
  digitalWrite(IN1,LOW);digitalWrite(IN2,LOW);
  digitalWrite(IN3,LOW);digitalWrite(IN4,LOW);
  allLightsOff(); digitalWrite(PIN_BRAKE,HIGH);
}

void setup(){
  BT.begin(9600);
  Serial.begin(9600);
  int pins[]={ENA,IN1,IN2,ENB,IN3,IN4,PIN_BRAKE,PIN_LEFT,PIN_RIGHT,PIN_REV};
  for(int p:pins)pinMode(p,OUTPUT);
  stopCar();
  Serial.println("RC Car Ready — waiting for Bluetooth...");
}

void loop(){
  if(BT.available()){
    char cmd = BT.read();
    Serial.print("CMD: "); Serial.println(cmd);
    switch(cmd){
      case 'F': forward();   break;
      case 'B': backward();  break;
      case 'L': turnLeft();  break;
      case 'R': turnRight(); break;
      case 'S': stopCar();   break;
      case 'H':
        updateBlink();
        digitalWrite(PIN_LEFT,blinkState);
        digitalWrite(PIN_RIGHT,blinkState);
        break;
      default:
        // Digits 0–9 set speed
        if(cmd>='0' && cmd<='9')
          carSpeed = map(cmd-'0',0,9,50,255);
        break;
    }
  }
}
